# АРХИВ ФАЙЛОВ ДЛЯ ИСПРАВЛЕНИЯ ГЕНЕРАЦИИ ТРЕБОВАНИЙ

## Структура архива

### BACKEND (PHP/Yii2):
- `RequirementGeneratorService.php` - основной сервис генерации требований
- `RequirementController.php` - контроллер API для пересчета требований
- `Requirement.php` - модель требования
- `Client.php` - модель клиента
- `main.php` - конфигурация роутинга API

### FRONTEND (Next.js/React/TypeScript):
- `page.tsx` - страница требований с формой пересчета
- `types.ts` - TypeScript типы
- `api.ts` - API клиент

### МИГРАЦИИ БД:
- `m240101_000003_create_clients_table.php` - создание таблицы clients
- `m240101_000004_create_requirements_table.php` - создание таблицы requirements
- `m240101_000010_add_requirement_fields.php` - добавление полей в requirements

### ДОКУМЕНТАЦИЯ:
- `Критерии_для_формирования_требований_.md` - критерии для проверки
- `tz.md` - техническое задание
- `ПРОМПТ_ДЛЯ_ИСПРАВЛЕНИЯ_ТРЕБОВАНИЙ.md` - промпт с описанием проблемы
