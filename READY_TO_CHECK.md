## 🔧 Команды для управления:

### Сброс и пересоздание всех демо-данных:
```bash
docker-compose exec backend php yii demo/reset
```

### Обычная загрузка данных:
```bash
docker-compose exec backend php yii seed
```

### Проверка статуса сервисов:
```bash
docker-compose ps
```

### Просмотр логов:
```bash
docker-compose logs -f backend
docker-compose logs -f frontend
```
