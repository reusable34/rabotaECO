## Для всех пользователей

### Страница требований (`/requirements`)
- Просмотр всех требований вашего клиента
- Статусы: ожидание, в работе, выполнено, не выполнено
- Фильтрация по категории, скважине, реке, побочному продукту
- **Вкладки:**
  - **Требования** - список требований
  - **Артефакты** - документы
  - **Календарь** - события и дедлайны
  - **Риски** - статьи КоАП с штрафами
  - **Законодательство** - справочник НПА
  - **Договоры** - договоры и акты
  - **Затраты** - (в разработке)
  - **Шаблоны** - (в разработке)

### Страница документов (`/documents`)
- **Загрузка:** Кнопка "Загрузить документ" → выберите файл → выберите тип → Загрузить

- Типы: Паспорт отходов, Журнал учёта, Инвентаризация, План НМУ, 2-ТП (воздух), Другое

### Страница календаря (`/calendar`)
- Просмотр событий с датами
- Отметка выполненных событий
- Добавление событий вручную

### Страница договоров (`/contracts`)
- Просмотр договоров и актов
- Статусы: Активен, Завершен

### Дашборд (`/dashboard`)
- Общая статистика
- Предстоящие события
- Требования в работе

## Для администратора

### Админ-панель (`/admin`)

#### Вкладка "Клиенты"
- **Создание клиента:**
  - Кнопка "+ Добавить клиента"
  - Заполните: название, категория НВОС (I-IV), скважина/река, побочный продукт, ответственный
  - Нажмите "Сохранить"
  - **Требования создаются автоматически** на основе категории и параметров
- **Редактирование:** Кнопка "Редактировать" у клиента
- **Удаление:** Кнопка "Удалить" у клиента
- **Просмотр требований:** Кнопка "Требования" у клиента → переход на страницу требований

#### Вкладка "Пользователи"
- **Создание пользователя:**
  - Кнопка "+ Добавить пользователя"
  - Заполните: имя, email, пароль, роль (админ/менеджер/специалист/клиент)
  - Выберите клиента для привязки (опционально)
  - Нажмите "Сохранить"
- **Привязка к клиенту:**
  - Кнопка "Редактировать" у пользователя
  - Выберите клиента в поле "Клиент"
  - Нажмите "Сохранить"
  - После привязки пользователь видит только данные своего клиента
- **Редактирование:** Кнопка "Редактировать" у пользователя
- **Удаление:** Кнопка "Удалить" у пользователя

#### Вкладка "Требования"
- Просмотр всех требований всех клиентов
- Фильтрация по клиенту
- **Добавление требования вручную:**
  - Кнопка "+ Добавить требование"
  - Выберите клиента, заполните название, статус, срок, ответственного, основание
  - Нажмите "Сохранить"
- **Редактирование:** Кнопка "Редактировать" у требования
- **Удаление:** Кнопка "Удалить" у требования

#### Вкладка "Справочник НПА"
- Просмотр нормативно-правовых актов
- **Добавление НПА:** Кнопка "+ Добавить НПА" → заполните код, название, ссылку, блок → Сохранить
- **Редактирование:** Кнопка "Редактировать" у НПА
- **Удаление:** Кнопка "Удалить" у НПА

#### Вкладка "Анкета клиента"
- Просмотр анкет клиентов

#### Вкладка "Дашборд"
- Общая статистика по системе

## Генерация требований

### На странице требований (`/requirements`)
1. Выберите клиента (если вы админ)
2. Заполните/измените параметры:
   - Категория НВОС (I, II, III, IV)
   - Скважина (да/нет)
   - Река/озеро (да/нет)
   - Побочный продукт (да/нет)
   - Ответственный
3. Нажмите **"Пересчитать требования"**
4. Система автоматически создаст/обновит требования:
   - Базовые требования по категории НВОС
   - + Лицензия на право пользования недрами (если скважина)
   - + Требования по водопользованию (если река/озеро)
   - + Технические условия на удобрения (если побочный продукт)

### При создании клиента
- Требования генерируются автоматически сразу после сохранения клиента
- Учитываются все параметры: категория, скважина, река, побочный продукт

## Права доступа

- **Администратор** - полный доступ ко всем данным, может управлять клиентами, пользователями, требованиями, НПА
- **Менеджер** - доступ только к данным своего клиента (если привязан)
- **Специалист** - доступ только к данным своего клиента (если привязан)
- **Клиент** - доступ только к своим данным

**Важно:** Пользователь должен быть привязан к клиенту в админ-панели, чтобы видеть данные.
