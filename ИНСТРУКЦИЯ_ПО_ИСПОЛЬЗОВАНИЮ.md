# Инструкция по использованию системы

## Вход в систему

**Регистрация:** `/register` - заполните имя, email, пароль  
**Авторизация:** `/login` - введите email и пароль

**Тестовые данные:**
- Админ: `admin@eco.local` / `admin123`
- Клиент: `client@demo.local` / `client123`

## Для администратора

### Админ-панель
Перейдите в **Админ-панель** (`/admin`)

### Управление клиентами
1. **Создание клиента:**
   - Админ-панель → Клиенты → "+ Добавить клиента"
   - Заполните: название, категория НВОС (I-IV), скважина/река, побочный продукт, ответственный
   - Нажмите "Сохранить"
   - **Требования создаются автоматически** на основе категории и параметров

2. **Редактирование:** Нажмите "Редактировать" у клиента

### Управление пользователями
1. **Создание пользователя:**
   - Админ-панель → Пользователи → "+ Добавить пользователя"
   - Заполните: имя, email, пароль, роль, клиент (опционально)
   - Нажмите "Сохранить"

2. **Привязка к клиенту:**
   - Редактируйте пользователя → выберите клиента в поле "Клиент" → Сохранить
   - После привязки пользователь видит только данные своего клиента

### Управление требованиями
1. **Добавление вручную:**
   - Админ-панель → Требования → "+ Добавить требование"
   - Выберите клиента, заполните название, статус, срок, ответственного
   - Нажмите "Сохранить"

2. **Редактирование:** Нажмите "Редактировать" у требования

### Генерация требований на странице требований
1. Перейдите на страницу **"Требования"** (`/requirements`)
2. Выберите клиента (если вы админ)
3. Заполните/измените параметры:
   - Категория НВОС (I, II, III, IV)
   - Скважина (если есть)
   - Река/озеро (если есть)
   - Побочный продукт (если есть)
   - Ответственный
4. Нажмите **"Пересчитать требования"**
5. Система автоматически создаст/обновит требования:
   - Базовые требования по категории
   - + Лицензия на недра (если скважина)
   - + Технические условия на удобрения (если побочный продукт)

### Документы
- **Загрузка:** `/documents` → "Загрузить документ" → выберите файл и тип
- **Скачивание:** Нажмите "Скачать" у документа
- Админ может загружать для любого клиента

### Справочник НПА
- Админ-панель → НПА
- Добавление, редактирование, удаление нормативно-правовых актов

## Автоматическое формирование требований

**Когда создаются требования:**
1. При создании нового клиента (автоматически)
2. При нажатии "Пересчитать требования" на странице требований

**Что учитывается:**
- **Категория НВОС** (I, II, III, IV) → базовые требования
- **Скважина** → добавляется "Лицензия на право пользования недрами"
- **Река/озеро** → добавляются требования по водопользованию
- **Побочный продукт** → добавляется "Технические условия на удобрения"

---

## Права доступа

- **Администратор** - полный доступ ко всем данным
- **Менеджер/Специалист/Клиент** - доступ только к данным своего клиента (если привязан)

**Важно:** Пользователь должен быть привязан к клиенту в админ-панели, чтобы видеть данные.
