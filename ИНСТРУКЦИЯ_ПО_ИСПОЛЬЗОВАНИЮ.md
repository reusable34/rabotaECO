# 📖 Инструкция по использованию системы

## 🔐 Вход в систему

### Регистрация новых пользователей
1. Перейдите на страницу регистрации (`/register`)
2. Заполните форму:
   - Имя
   - Email
   - Пароль
3. Нажмите "Зарегистрироваться"
4. После регистрации вы автоматически войдете в систему

### Авторизация
1. Перейдите на страницу входа (`/login`)
2. Введите email и пароль
3. Нажмите "Войти"

**Тестовые учетные данные:**
- **Администратор:** `admin@eco.local` / `admin123`
- **Менеджер:** `manager@eco.local` / `manager123`
- **Клиент:** `client@demo.local` / `client123`

---

## 👤 Работа для обычных пользователей (Клиент, Менеджер, Специалист)

### Просмотр требований
1. После входа вы попадете на страницу **"Требования"** (`/requirements`)
2. Вы увидите список всех требований вашего клиента
3. Требования отображаются с:
   - Названием
   - Статусом (в работе, выполнено, не выполнено, ожидание)
   - Сроком выполнения
   - Ответственным лицом
   - Связанными рисками (статьи КоАП)

### Работа с документами
1. Перейдите на вкладку **"Артефакты"** на странице требований или на страницу `/documents`
2. **Загрузка документа:**
   - Нажмите кнопку "Загрузить документ"
   - Выберите файл (PDF, DOCX, XLSX, DOC, XLS, JPG, PNG, TXT)
   - Выберите тип документа из списка
   - Нажмите "Загрузить"
3. **Скачивание документа:**
   - Найдите нужный документ в списке
   - Нажмите кнопку "Скачать"
   - Файл автоматически загрузится на ваш компьютер

### Календарь событий
1. Перейдите на вкладку **"Календарь"** на странице требований
2. Просматривайте предстоящие и прошедшие события
3. События автоматически создаются на основе требований

### Просмотр рисков
1. Перейдите на вкладку **"Риски"** на странице требований
2. Увидите все риски по статьям КоАП с диапазонами штрафов
3. Риски привязаны к конкретным требованиям

### Договоры
1. Перейдите на вкладку **"Договоры"** на странице требований
2. Просматривайте список договоров и актов
3. Видите статусы договоров (Активен, Завершен)

## 👨‍💼 Работа для администратора

### Админ-панель
1. Войдите как администратор
2. Перейдите в **Админ-панель** (кнопка в меню или `/admin`)
3. В админ-панели доступны вкладки:
   - **Дашборд** - общая статистика
   - **Пользователи** - управление пользователями
   - **Клиенты** - управление клиентами
   - **Требования** - управление требованиями
   - **НПА** - справочник нормативно-правовых актов

### Управление клиентами

#### Создание нового клиента
1. Перейдите в админ-панель → вкладка **"Клиенты"**
2. Нажмите кнопку **"+ Добавить клиента"**
3. Заполните форму:
   - **Название** - название компании (обязательно)
   - **Категория** - выберите категорию НВОС (I, II, III, IV) (обязательно)
   - **Водопользование:**
     - Выберите "Скважина" если есть скважина
     - Выберите "Река/озеро" если есть река или озеро
   - **Побочный продукт** - отметьте, если есть побочная продукция (животноводство)
   - **Ответственный** - ФИО ответственного лица
4. Нажмите **"Сохранить"**
5. После создания клиента автоматически сформируются требования на основе:
   - Выбранной категории НВОС
   - Параметров водопользования (скважина/река)
   - Наличия побочной продукции

#### Редактирование клиента
1. В списке клиентов нажмите **"Редактировать"** у нужного клиента
2. Измените необходимые поля
3. Нажмите **"Сохранить"**

#### Удаление клиента
1. В списке клиентов нажмите **"Удалить"** у нужного клиента
2. Подтвердите удаление
3. ⚠️ **Внимание:** При удалении клиента удаляются все связанные требования, документы, договоры и события

### Управление пользователями

#### Создание пользователя
1. Перейдите в админ-панель → вкладка **"Пользователи"**
2. Нажмите кнопку **"+ Добавить пользователя"**
3. Заполните форму:
   - **Имя** (обязательно)
   - **Email** (обязательно)
   - **Пароль** (обязательно при создании)
   - **Роль:**
     - Администратор - полный доступ ко всем данным
     - Менеджер - доступ только к своим клиентам
     - Специалист - доступ к своим проектам
     - Клиент - доступ только к своим данным
   - **Клиент** - выберите клиента для привязки (опционально)
4. Нажмите **"Сохранить"**

#### Привязка пользователя к клиенту
1. В списке пользователей нажмите **"Редактировать"** у нужного пользователя
2. В поле **"Клиент"** выберите клиента из списка
3. Нажмите **"Сохранить"**
4. После привязки пользователь будет видеть:
   - Только требования своего клиента
   - Только категорию своего клиента
   - Только документы своего клиента
   - Только договоры своего клиента

#### Редактирование пользователя
1. В списке пользователей нажмите **"Редактировать"**
2. Измените необходимые поля
3. Пароль можно оставить пустым - он не изменится
4. Нажмите **"Сохранить"**

#### Удаление пользователя
1. В списке пользователей нажмите **"Удалить"**
2. Подтвердите удаление
3. ⚠️ **Внимание:** Нельзя удалить самого себя

### Управление требованиями

#### Просмотр требований
1. Перейдите в админ-панель → вкладка **"Требования"**
2. Выберите клиента из фильтра (опционально)
3. Просматривайте все требования выбранного клиента или всех клиентов

#### Добавление требования вручную
1. В админ-панели → вкладка **"Требования"**
2. Нажмите кнопку **"+ Добавить требование"**
3. Заполните форму:
   - **Клиент** - выберите клиента (обязательно)
   - **Название** - название требования (обязательно)
   - **Статус** - выберите статус (ожидание, в работе, выполнено, не выполнено)
   - **Срок выполнения** - укажите дату дедлайна
   - **Ответственный** - ФИО ответственного лица
   - **Основание** - нормативно-правовое основание
4. Нажмите **"Сохранить"**

#### Редактирование требования
1. В списке требований нажмите **"Редактировать"**
2. Измените необходимые поля
3. Нажмите **"Сохранить"**

#### Удаление требования
1. В списке требований нажмите **"Удалить"**
2. Подтвердите удаление

### Генерация требований на странице требований

#### Пересчет требований для клиента
1. Перейдите на страницу **"Требования"** (`/requirements`)
2. Если вы админ, выберите клиента из списка или перейдите по ссылке из админ-панели
3. Заполните или измените параметры:
   - **Категория НВОС** - выберите категорию (I, II, III, IV)
   - **Скважина** - отметьте, если есть скважина
   - **Река/озеро** - отметьте, если есть река или озеро
   - **Побочный продукт** - отметьте, если есть побочная продукция
   - **Ответственный** - укажите ответственное лицо
4. Нажмите кнопку **"Пересчитать требования"**
5. Система автоматически:
   - Создаст базовые требования для выбранной категории
   - Добавит требование "Лицензия на право пользования недрами" (если выбрана скважина)
   - Добавит требование "Технические условия на удобрения" (если выбран побочный продукт)
   - Обновит существующие требования

**Как формируются требования:**
- **Базовые требования** зависят от категории НВОС (I, II, III, IV)
- **Дополнительные требования:**
  - Если есть **скважина** → добавляется "Лицензия на право пользования недрами"
  - Если есть **река/озеро** → добавляются требования по водопользованию
  - Если есть **побочный продукт** → добавляется "Технические условия 'Удобрения органические на основе побочной продукции животноводства'"

### Работа с документами (для администратора)

#### Загрузка документа
1. Перейдите на страницу **"Документы"** (`/documents`)
2. Нажмите **"Загрузить документ"**
3. Выберите файл
4. Выберите тип документа
5. Если вы админ, система может запросить `client_id` - укажите его или убедитесь, что вы привязаны к клиенту
6. Нажмите **"Загрузить"**

#### Скачивание документа
1. Найдите нужный документ в списке
2. Нажмите **"Скачать"**
3. Файл загрузится на ваш компьютер

**Доступные типы документов:**
- Паспорт отходов
- Журнал учёта движения отходов
- Инвентаризация
- План НМУ
- 2-ТП (воздух)
- Другое

### Справочник НПА (Нормативно-правовые акты)

1. Перейдите в админ-панель → вкладка **"НПА"**
2. Просматривайте список нормативно-правовых актов
3. Добавляйте новые НПА:
   - Нажмите **"+ Добавить НПА"**
   - Заполните: код, название, ссылку, блок
   - Нажмите **"Сохранить"**
4. Редактируйте или удаляйте существующие НПА

## 🔄 Автоматическое формирование требований

Система автоматически формирует требования при:
1. **Создании нового клиента** - требования создаются сразу после сохранения клиента
2. **Пересчете требований** - на странице требований при нажатии кнопки "Пересчитать требования"

**Логика формирования:**
- Базовые требования зависят от **категории НВОС** (I-IV)
- Дополнительные требования добавляются на основе:
  - **Скважина** → Лицензия на недра
  - **Река/озеро** → Требования по водопользованию
  - **Побочный продукт** → Технические условия на удобрения

---

## 📋 Статусы требований

- **Ожидание** (`pending`) - требование создано, но еще не начато
- **В работе** (`in_progress`) - требование выполняется
- **Выполнено** (`completed`) - требование выполнено
- **Не выполнено** (`not_completed`) - требование не выполнено в срок

## 🔒 Права доступа

### Администратор
- Полный доступ ко всем данным
- Может создавать, редактировать и удалять клиентов, пользователей, требования
- Может загружать документы для любого клиента
- Может скачивать любые документы

### Менеджер
- Доступ только к данным своего клиента (если привязан)
- Может просматривать требования, документы, договоры своего клиента
- Может загружать и скачивать документы своего клиента

### Специалист
- Доступ только к данным своего клиента (если привязан)
- Может просматривать требования, документы, договоры своего клиента
- Может загружать и скачивать документы своего клиента

### Клиент
- Доступ только к своим данным
- Может просматривать свои требования, документы, договоры
- Может загружать и скачивать свои документы

## 💡 Полезные советы

1. **Привязка пользователя к клиенту:**
   - Администратор должен привязать пользователя к клиенту в админ-панели
   - После привязки пользователь автоматически увидит все данные своего клиента

2. **Генерация требований:**
   - При создании клиента требования генерируются автоматически
   - Для пересчета требований используйте кнопку "Пересчитать требования" на странице требований

3. **Работа с документами:**
   - Документы хранятся в файловой системе на сервере
   - При загрузке убедитесь, что у сервера есть права на запись в директорию `storage`

4. **Календарь событий:**
   - События автоматически создаются на основе требований
   - Можно добавлять события вручную на вкладке "Календарь"

## ❓ Часто задаваемые вопросы

**Q: Как привязать пользователя к клиенту?**  
A: В админ-панели → Пользователи → Редактировать → Выбрать клиента → Сохранить

**Q: Почему я не вижу требований?**  
A: Убедитесь, что вы привязаны к клиенту. Обратитесь к администратору.

**Q: Как пересчитать требования для клиента?**  
A: Перейдите на страницу требований, выберите клиента, измените параметры и нажмите "Пересчитать требования"

**Q: Почему не могу загрузить документ?**  
A: Убедитесь, что у сервера есть права на запись в директорию storage. Обратитесь к администратору.

**Q: Как скачать документ?**  
A: Найдите документ в списке и нажмите кнопку "Скачать"
