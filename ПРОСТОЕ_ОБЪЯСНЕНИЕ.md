# Простое объяснение: что нужно сделать

## Что это за система?

Это **личный кабинет для клиентов** вашей компании (ГлавПриродБюро), которая помогает предприятиям соблюдать экологическое законодательство.

## Зачем это нужно?

Ваши клиенты (заводы, фабрики, предприятия) должны выполнять кучу экологических требований:
- Сдавать отчеты
- Получать разрешения
- Вести журналы
- Платить за загрязнение окружающей среды

**Проблема:** клиенты не знают, какие требования к ним относятся, когда что сдавать, где хранить документы.

**Решение:** создать сайт, где всё это автоматически показывается для каждого клиента.

---

## Что должно быть на сайте? (простым языком)

### 1. **Карта требований** (главное!)

**Что это:** список всех экологических требований, которые относятся к конкретному клиенту.

**Как работает:**
- Вы заводите нового клиента в систему
- Заполняете анкету: какая категория (I, II, III или IV), есть ли скважина, есть ли побочный продукт
- Система **автоматически** показывает список требований для этого клиента

**Пример:**
- Клиент 3 категории → система показывает 15 требований
- У клиента есть скважина → добавляется требование "Лицензия на недра"
- У клиента есть побочный продукт → добавляется требование "Технические условия на удобрения"

**Как выглядит на сайте:**
- Таблица с колонками:
  - **Требование** (например, "Журнал учета отходов")
  - **Основание** (например, "КоАП РФ 8.2" - ссылка на закон)
  - **Артефакты** (какие документы нужны: "Журнал", "Отчет")
  - **Год документа** (2025)
  - **Статус** (Выполнено / В работе / Не выполнено)
  - **Срок выполнения** (например, "март 2025")
  - **Ответственный** (ФИО человека, кто отвечает)

### 2. **Артефакты/Хранилище** (документы)

**Что это:** место, где хранятся все экологические документы клиента.

**Как работает:**
- Вы загружаете документы, которые сделали для клиента (разрешения, отчеты, паспорта)
- Клиент может сам загружать документы (если делал не вы)
- Можно скачивать документы

**Как выглядит на сайте:**
- Список документов с названиями
- Кнопка "Загрузить документ"
- Кнопка "Скачать" у каждого документа
- Статус документа (На проверке / Одобрен / Отклонён)

### 3. **Календарь событий**

**Что это:** календарь с датами, когда нужно сдавать отчеты и платить.

**Как работает:**
- Система автоматически создает события на основе требований
- Когда отчет сдан, дата закрывается и ставится новая на следующий период

**Как выглядит на сайте:**
- Два раздела:
  - **Предстоящие события** (что нужно сделать)
  - **Прошедшие события** (что уже сделано)

### 4. **Риски**

**Что это:** что будет, если клиент не выполнит требование (штрафы по КоАП).

**Как работает:**
- К каждому требованию привязаны статьи КоАП
- Показывается диапазон штрафов

**Как выглядит на сайте:**
- Список требований
- Под каждым требованием - риски:
  - Статья КоАП (например, "8.21 ч.1")
  - Штраф (например, "50 000 - 100 000 ₽")

### 5. **Договора/счета/акты**

**Что это:** хранилище всех финансовых документов по клиенту.

**Как работает:**
- Вы загружаете договоры, счета, акты
- У каждого документа есть статус (Черновик / Активен / Завершён / Отменён)

**Как выглядит на сайте:**
- Список договоров с номерами
- Статус каждого договора
- Дата договора

### 6. **Изменения в законодательстве** (пока заглушка)

**Что это:** новости об изменениях в экологическом законодательстве.

### 7. **Снижение затрат** (пока заглушка)

**Что это:** рекомендации, как клиент может снизить затраты на экологию.

### 8. **Шаблоны** (пока заглушка)

**Что это:** шаблоны документов, которые можно скачать и заполнить.

---

## Как это работает для клиента?

1. **Клиент регистрируется** на сайте
2. **Входит в личный кабинет**
3. **Видит свою карту требований:**
   - Какие требования к нему относятся
   - Какие документы нужны
   - Когда что сдавать
   - Что уже выполнено, что в работе
4. **Может загружать документы** в хранилище
5. **Смотрит календарь** - когда что сдавать
6. **Видит риски** - что будет, если не выполнит

---

## Как это работает для вас (сотрудников)?

1. **Заводите нового клиента:**
   - Заполняете анкету (категория, скважина, побочный продукт)
   - Система автоматически создает список требований

2. **Работаете с клиентом:**
   - Меняете статусы требований (в работе → выполнено)
   - Загружаете документы, которые сделали
   - Добавляете договоры/счета/акты

3. **Календарь обновляется автоматически:**
   - Когда отчет сдан, дата закрывается
   - Ставится новая дата на следующий период
