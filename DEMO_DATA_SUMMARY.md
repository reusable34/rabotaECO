# 📊 Сводка демо-данных

## ✅ Созданные компоненты

### 1. Сервисы генерации данных

#### `RequirementGeneratorService`
- **Путь:** `backend/common/services/RequirementGeneratorService.php`
- **Функционал:** Автоматическая генерация требований на основе:
  - Категории НВОС (I–IV)
  - Наличия скважины (`has_well`)
  - Наличия реки (`has_river`)
  - Наличия побочной продукции (`has_byproduct`)
- **Матрица требований:** Полностью соответствует таблице из `requirements.md`

#### `DemoDataGeneratorService`
- **Путь:** `backend/common/services/DemoDataGeneratorService.php`
- **Функционал:** Генерация полного набора демо-данных:
  - Требования (15–20 шт.)
  - Риски (статьи КоАП + штрафы)
  - События (календарь)
  - Документы
  - Договоры

### 2. Команда сброса демо-данных

#### `php yii demo/reset`
- **Путь:** `backend/console/controllers/DemoController.php`
- **Функционал:**
  1. Очистка существующих данных демо-клиента
  2. Применение миграций
  3. Загрузка базовых данных (категории, пользователи)
  4. Создание демо-клиента с полным набором данных
  5. Генерация всех демо-данных
  6. Вывод статистики

## 📋 Созданные демо-данные

### Демо-клиент
- **Название:** Демо-клиент
- **Категория:** II категория НВОС
- **Параметры:**
  - ✅ Скважина (`has_well = true`)
  - ❌ Река (`has_river = false`)
  - ✅ Побочная продукция (`has_byproduct = true`)

### Требования (20 шт.)

#### Статусы:
- ✅ **Выполнено** (`completed`) — 3 требования
- 🔄 **В работе** (`in_progress`) — 6 требований
- ⏳ **Ожидание** (`pending`) — 8 требований
- ❌ **Не выполнено** (`not_completed`) — 3 требования

#### Примеры требований:
1. Журнал учёта движения отходов
2. Журнал учёта источников выбросов
3. 2-ТП (воздух)
4. 2-ТП (отходы)
5. Декларация о плате за НВОС
6. Отчёт ПЭК
7. Инвентаризация выбросов
8. Инвентаризация отходов
9. Паспорт отходов I–IV класса
10. НООЛР
11. НДВ
12. Экспертное заключение на НДВ
13. СЭЗ на проект НДВ (Роспотребнадзор)
14. План НМУ
15. ППЭК
16. ДВОС (II категория)
17. Проект СЗЗ
18. Решение об установлении СЗЗ
19. Лицензия на пользование недрами
20. Технические условия "Удобрения органические на основе побочной продукции животноводства"

#### Дополнительные требования:
- Отчёт о выполнении мероприятий по охране окружающей среды
- Программа производственного экологического контроля
- Декларация о количестве выбросов загрязняющих веществ
- Справка о наличии источников выбросов
- Расчёт нормативов допустимых выбросов

### Риски (20 шт.)

Каждое требование связано с риском (статья КоАП + штрафы):

- **8.2 КоАП:** 20 000 – 100 000 ₽
- **8.21 КоАП:** 40 000 – 200 000 ₽
- **8.1 КоАП:** 10 000 – 250 000 ₽
- **8.5 КоАП:** 30 000 – 150 000 ₽
- **8.46 КоАП:** 50 000 – 300 000 ₽

### События (5 шт.)

#### Будущие события (3):
1. **Сдача отчёта 2-ТП (воздух)** — через 15 дней
2. **Сдача отчёта 2-ТП (отходы)** — через 30 дней
3. **Подача Декларации о плате за НВОС** — через 45 дней

#### Прошедшие события (2):
1. **Сдача Журнала учёта движения отходов** — 20 дней назад ✅
2. **Проверка Росприроднадзора** — 10 дней назад ✅

### Документы (5 шт.)

#### Статусы:
- ✅ **Одобрено** (`approved`) — 2 документа
- ⏳ **В ожидании** (`pending`) — 2 документа
- ❌ **Отклонено** (`rejected`) — 1 документ

#### Примеры документов:
1. Журнал учёта (`journal_otkhody.pdf`) — ✅ Одобрено
2. Отчёт 2-ТП (`2tp_vozdukh.xlsx`) — ⏳ В ожидании
3. Паспорт отходов (`pasport_otkhodov.pdf`) — ⏳ В ожидании
4. План НМУ (`plan_nmu.docx`) — ❌ Отклонено
5. Инвентаризация (`inventarizatsiya.pdf`) — ✅ Одобрено

### Договоры (2 шт.)

1. **ДОГ-2024-001** — Активный (`active`) — от 30 дней назад
2. **АКТ-2024-001** — Завершён (`completed`) — от 10 дней назад

## 🚀 Использование

## ✅ Проверка данных

### Через API:

```bash
# Получить требования
curl -H "Authorization: Bearer <token>" http://localhost:8080/requirement

# Получить события
curl -H "Authorization: Bearer <token>" http://localhost:8080/event

# Получить документы
curl -H "Authorization: Bearer <token>" http://localhost:8080/document

# Получить договоры
curl -H "Authorization: Bearer <token>" http://localhost:8080/contract
```

### Через базу данных:

```bash
docker-compose exec db psql -U eco_admin -d eco_client

# Проверить требования
SELECT COUNT(*) FROM requirements WHERE client_id = (SELECT id FROM clients WHERE name = 'Демо-клиент');

# Проверить события
SELECT * FROM events WHERE client_id = (SELECT id FROM clients WHERE name = 'Демо-клиент');

# Проверить документы
SELECT * FROM documents WHERE client_id = (SELECT id FROM clients WHERE name = 'Демо-клиент');
```
