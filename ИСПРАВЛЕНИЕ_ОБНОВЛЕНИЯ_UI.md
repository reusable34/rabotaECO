# Исправление обновления UI после пересчета требований

**Проблема:** После нажатия "Пересчитать требования" данные на странице не обновлялись, хотя API работал правильно.

## Найденные проблемы:

1. **Не создавался новый массив** - React не видел изменения, если массив требований не менял ссылку
2. **Неправильный синтаксис параметров axios** - использовался объект `params`, но нужно было использовать query string
3. **Не было принудительного обновления** - React мог не заметить изменения

## Исправления:

### Frontend (frontend/app/requirements/page.tsx):

1. ✅ Исправлен синтаксис запроса - используется query string вместо объекта params
2. ✅ Добавлено создание нового массива через `slice()` для принудительного обновления React
3. ✅ Добавлено логирование для отладки
4. ✅ Улучшена обработка обновления данных клиента

### Изменения в коде:

```typescript
// Было:
const requirementsRes = await api.get('/requirement');
setRequirements(reqs);

// Стало:
const requirementsRes = await api.get(`/requirement?_t=${Date.now()}`);
setRequirements(reqs.slice()); // Создаем новый массив
```
