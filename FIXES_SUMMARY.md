## 🚀 Запуск проекта

Проект теперь запускается тремя командами:

```bash
# 1. Запуск всех сервисов
docker-compose up -d

# 2. Выполнение миграций
docker-compose exec backend php yii migrate

# 3. Загрузка тестовых данных
docker-compose exec backend php yii seed
```

После этого проект доступен по адресу http://localhost:3000
