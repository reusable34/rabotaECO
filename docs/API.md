# API Документация

## Базовый URL

```
http://localhost:8080
```

## Аутентификация

Все защищённые эндпоинты требуют JWT токен в заголовке:

```
Authorization: Bearer <token>
```

## Эндпоинты

### Авторизация

#### POST /auth/login
Вход в систему

**Тело запроса:**
```json
{
  "email": "client@demo.local",
  "password": "client123"
}
```

**Ответ:**
```json
{
  "token": "eyJ0eXAiOiJKV1QiLCJhbGc...",
  "user": {
    "id": 1,
    "name": "Клиент Демо",
    "email": "client@demo.local",
    "role": "client",
    "client_id": 1
  }
}
```

#### POST /auth/register
Регистрация нового пользователя

**Тело запроса:**
```json
{
  "name": "Иван Иванов",
  "email": "ivan@example.com",
  "password": "password123"
}
```

### Клиенты

#### GET /client
Получить список клиентов (доступ зависит от роли)

#### GET /client/{id}
Получить информацию о клиенте

#### POST /client
Создать нового клиента (только для admin/manager)

**Тело запроса:**
```json
{
  "name": "Новый клиент",
  "category_id": 2,
  "has_well": true,
  "has_river": false,
  "has_byproduct": true
}
```

### Требования

#### GET /requirement
Получить список требований

#### GET /requirement/{id}
Получить информацию о требовании

#### GET /requirement/{id}/risks
Получить риски для требования

### Документы

#### GET /document
Получить список документов

#### POST /document/upload
Загрузить документ

**Форма:**
- `file`: файл
- `client_id`: ID клиента

### Договоры

#### GET /contract
Получить список договоров

#### GET /contract/{id}
Получить информацию о договоре

### События

#### GET /event
Получить список событий

#### GET /event/{id}
Получить информацию о событии

### Категории

#### GET /category
Получить список категорий НВОС

### Риски

#### GET /risk
Получить список рисков

## Коды ответов

- `200` - Успешный запрос
- `201` - Ресурс создан
- `400` - Неверный запрос
- `401` - Не авторизован
- `403` - Доступ запрещён
- `404` - Ресурс не найден
- `500` - Внутренняя ошибка сервера
