# ✅ Проект готов по ТЗ!

## Что реализовано

### 1. ✅ Регистрация
- Страница `/register` с формой регистрации
- Поля: ФИО, Email, Пароль, Подтверждение пароля
- Валидация и проверка паролей
- Ссылка на регистрацию со страницы входа

### 2. ✅ Админ панель (`/admin`)
- Доступна только администраторам
- Автоматическая проверка доступа
- Ссылка в навигации (только для админов)

**Разделы админ панели:**

#### Пользователи
- Список пользователей (заглушка, будет доработана)

#### Клиенты
- Список всех клиентов
- Показывает: ID, название, категорию, параметры (скважина, река, побочный продукт), ответственного

#### Анкета клиента (главное!)
- **Полная форма как на скриншоте:**
  - Раздел 1: Данные юрлица и контакты
    - Юрлицо / бренд
    - ИНН / ОГРН
    - ОКВЭД(ы) / сфера
    - Ответственный (ФИО, роль)
    - Email / телефон
  - Раздел 2: Площадка
    - Название площадки / адрес
    - Категория НВОС (выпадающий список)
    - Стац. источники выбросов
    - Тип канализации
    - Источник водопользования (Нет / Скважина / Река)
    - Лицензия на недра (если скважина)
    - Чекбокс "Есть побочный продукт"
- **При создании клиента:**
  - Автоматически формируются требования на основе категории и параметров
  - После создания переход на вкладку "Клиенты"

#### Требования
- Список всех требований
- Кнопка "+ Добавить требование"
- Кнопки "Редактировать" и "Удалить" у каждого требования
- Модальное окно редактирования:
  - Название
  - Статус (Ожидание / В работе / Выполнено / Не выполнено)
  - Срок выполнения
  - Ответственный
  - Основание (КоАП статья)

### 3. ✅ Карта требований
- Таблица с колонками:
  - Требования
  - Основание (ссылка)
  - Артефакты
  - Год документа
  - Статусы (цветные бейджи)
  - Срок выполнения
  - Ответственный
- Фильтры для пересчета требований
- Кнопка "Пересчитать требования"

### 4. ✅ Вкладки на странице требований
Все 8 вкладок работают и переключаются:
- Карта требований
- Артефакты/хранилище
- Календарь событий
- Риски
- Изменения в законодательстве (заглушка)
- Договора/счета/акты
- Снижение затрат (заглушка)
- Шаблоны (заглушка)

## Как использовать

### Для клиента:
1. Зарегистрироваться на `/register`
2. Войти в систему на `/login`
3. Видеть свою карту требований
4. Загружать/скачивать документы
5. Смотреть календарь событий
6. Видеть риски

### Для администратора:
1. Войти как админ:
   - Email: `admin@eco.local`
   - Password: `admin123`
2. В навигации появится ссылка "Админ панель"
3. Перейти в админ панель
4. На вкладке "Анкета клиента":
   - Заполнить форму
   - Нажать "Создать клиента и сформировать требования"
   - Система автоматически создаст клиента и сформирует требования
5. На вкладке "Требования":
   - Можно редактировать требования вручную
   - Можно добавлять новые требования
   - Можно удалять требования
