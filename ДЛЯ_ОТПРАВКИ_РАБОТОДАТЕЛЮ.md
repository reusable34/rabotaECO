# Личный кабинет клиента по экологии

## Краткое описание проекта

Реализован полнофункциональный прототип личного кабинета клиента для управления экологическими требованиями. Проект создан с использованием нейросетей (GPT-4 через Cursor IDE) для генерации кода и дизайна.

## Технологический стек

- **Backend:** Yii2 Advanced (REST API)
- **Frontend:** Next.js 14 + TypeScript + SCSS
- **Database:** PostgreSQL 15
- **Containerization:** Docker Compose
- **Authentication:** JWT

## Основной функционал

### Для клиента:
- Личный кабинет с дашбордом
- Карта требований с фильтрами
- Загрузка и скачивание документов
- Календарь событий и дедлайнов
- Просмотр договоров

### Для администратора:
- Управление клиентами (CRUD)
- Управление требованиями (добавить/исключить/переназначить)
- Управление пользователями и ролями
- Справочник НПА
- Анкета нового клиента с автоматическим формированием требований

## Автоматическое формирование требований

Система автоматически создает карту требований на основе:
- Категории НВОС (I, II, III, IV)
- Источника водопользования (скважина / река)
- Наличия побочной продукции

## Запуск проекта

```bash
# 1. Клонировать репозиторий
git clone <repository-url>
cd rabotaECO

# 2. Запустить Docker контейнеры
docker-compose up -d

# 3. Применить миграции
docker-compose exec backend php yii migrate

# 4. Загрузить тестовые данные
docker-compose exec backend php yii seed

# 5. Открыть в браузере
# http://localhost:3000
```
