## 🔧 КОМАНДЫ ДЛЯ ПРОВЕРКИ

### Запустить все тесты
```bash
docker exec eco_backend php /var/www/html/console/yii test-requirements/test-all
```

### Проверить конкретную категорию
```bash
docker exec eco_backend php /var/www/html/console/yii test-requirements/test-category 3 0 0 0
```

### Проверить требования в БД для всех клиентов
```bash
docker exec eco_backend php /var/www/html/console/yii check-requirements/check-all
```

### Принудительно пересчитать требования для всех клиентов
```bash
docker exec eco_backend php /var/www/html/console/yii recalculate-all/all
```

### Пересчитать требования для конкретного клиента
```bash
docker exec eco_backend php /var/www/html/console/yii recalculate-all/client 1
```

## ⚠️ ВАЖНО

Если в интерфейсе отображается неправильное количество требований:

1. **Пересчитайте требования** через кнопку "Пересчитать требования" в интерфейсе
2. **Проверьте логи** в `backend/api/runtime/logs/app.log` - там будет видно, что именно создается
3. **Очистите кэш браузера** - возможно, отображаются старые данные
4. **Проверьте БД напрямую** используя команду `check-requirements/check-all`
