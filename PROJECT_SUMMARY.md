## 🎯 Основной функционал

### Автоматическое формирование требований
Система автоматически создаёт карту требований на основе:
- Категории НВОС (I–IV) - применяется матрица из requirements.md
- Наличия скважины → добавляется требование "Лицензия на пользование недрами"
- Наличия реки → добавляются требования "Решение на водопользование" и "Договор водопользования"
- Наличия побочной продукции → добавляется требование "Технические условия..."

### Роли и доступы
- **admin** - полный доступ ко всем клиентам
- **manager** - доступ только к своим клиентам
- **specialist** - доступ к своим проектам
- **client** - доступ только к своим данным

### Демо-данные
Создаётся демо-клиент:
- Категория II
- Есть скважина
- Есть побочный продукт
- Автоматически формируются все требования

## 🚀 Быстрый старт

1. Клонировать репозиторий
2. Скопировать `.env.example` в `.env`
3. Запустить `docker-compose up -d`
4. Выполнить миграции: `docker-compose exec backend php yii migrate`
5. Загрузить данные: `docker-compose exec backend php yii seed`
6. Открыть http://localhost:3000
